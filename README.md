# Compra Tu Juego 🎮

Demo frontend de una tienda gamer para regalar juegos. Hecha con HTML, CSS y JavaScript puro; lista para publicar en GitHub Pages.

## Funcionalidades
- Catálogo adaptable a móvil y escritorio, búsqueda y filtros por género.
- Ventana flotante para ingresar el tag del destinatario.
- Checkout con Visa predeterminada terminada en **5821**.
- Pantalla de revisión y confirmación.
- Confirmación de demo: “¡Compra realizada! Regalo enviado”.
- Historial de compras de demostración guardado en `localStorage`.

## Ejecutar localmente
Abrí `index.html` en tu navegador. No requiere instalación ni dependencias.

## Publicar en GitHub Pages
1. Creá un repositorio en GitHub.
2. Subí todos los archivos de esta carpeta.
3. Entrá en **Settings → Pages**.
4. En **Build and deployment**, elegí **Deploy from a branch**.
5. Elegí la rama `main` y la carpeta `/ (root)`, y guardá.

## Importante
Este proyecto es una demostración visual. No procesa pagos reales ni entrega licencias de juegos. Los precios son ilustrativos y los productos/imágenes son referencias visuales. Para vender de verdad necesitás integrar un backend seguro, un proveedor de pagos y un sistema autorizado de distribución. No se almacenan datos de tarjetas; solo se muestra una tarjeta de prueba enmascarada.
